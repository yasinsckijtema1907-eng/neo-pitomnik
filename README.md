# НЭО Питомник

Многостраничный сайт питомника с каталогом из 188 позиций, 33 категориями, девятью услугами, журналом и объёмной анимацией роста хвойного дерева при прокрутке. Данные и фотографии растений сохранены с исходного сайта https://neo-pitomnik.ru/.

Дизайн: архитектурная композиция, крупная типографика, светлый каменный фон и глубокий лесной зелёный. Атмосферное изображение первого экрана создано с помощью встроенного imagegen; это иллюстрация образа сада, а не фотография реализованного проекта питомника. Оригинал и точный запрос находятся в `public/assets/premium-hero.png` и `public/assets/premium-hero-prompt.txt`, оптимизированная версия для сайта — `premium-hero.webp`. В карточках растений используются только реальные исходные фотографии.

**Сайт:** https://yasinsckijtema1907-eng.github.io/neo-pitomnik/

Сразу после первого экрана расположена 3D-сцена: семечко, первый росток, молодое и взрослое дерево. Модели Poly Haven используют настоящие PBR-текстуры 4096×4096 и лицензию CC0. Дерево можно поворачивать перетаскиванием или кнопками. На телефоне сначала показаны кадры 2160×3840, отрендеренные из этой же геометрии; интерактивная модель с картами 2048×2048 загружается по желанию посетителя. При недоступном WebGL сохраняется анимация кадров. Источники, авторы и контрольные суммы находятся в `public/assets/trees/MODEL-LICENSES.md` и соседних JSON-файлах.

В разделе «О питомнике» возвращены оригинальная общая фотография команды и все шесть портретов. Источники изображений перечислены в `public/assets/team/sources.json`; имена и индивидуальные должности не выдумывались.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

## Сборка для GitHub Pages

```sh
# Bash / Linux / macOS
NEXT_PUBLIC_BASE_PATH=/neo-pitomnik NEXT_PUBLIC_SITE_ORIGIN=https://yasinsckijtema1907-eng.github.io npm run build
```

```powershell
$env:NEXT_PUBLIC_BASE_PATH='/neo-pitomnik'
$env:NEXT_PUBLIC_SITE_ORIGIN='https://yasinsckijtema1907-eng.github.io'
npm run build
```

Готовый сайт находится в `out/`. Все страницы генерируются отдельными HTML-файлами. GitHub Actions автоматически собирает и публикует сайт после изменения ветки `main`.

## Заявки

Выбор растений хранится в браузере. Форма готовит письмо на `admin@neo-pitomnik.ru` с контактами и выбранными позициями. Посетитель открывает и отправляет письмо из своей почты; сайт не сообщает об автоматической отправке или сохранении заявки.

Оригинальный обработчик заявок для OpenAI Sites и Cloudflare D1 сохранён в `server/sites-inquiry-route.ts`, схема — в `db/` и `drizzle/`. Этот обработчик не запускается на GitHub Pages. Для автоматического приёма заявок понадобится отдельный сервер.

## Где редактировать

- `app/garden.tsx` — каталог, выбор растений, заявки и управление анимацией дерева;
- `app/premium-experience.tsx` — главная страница, навигация, футер и оформление описаний;
- `app/page-content.tsx` — содержание основных разделов;
- `app/about-team.tsx` — общая фотография и галерея команды;
- `app/growth-experience.tsx` и `app/tree-scene.tsx` — история роста и интерактивная 3D-сцена;
- `app/premium.css` — действующая система стилей для всех страниц;
- `app/refined.css` — оформление крупной сцены и блока команды;
- `public/catalog.json` — исходный ассортимент и цены;
- `public/blog.json` — статья исходного блога;
- `public/assets/` — фотографии, шрифты и кадры анимации.

У части товаров на исходном сайте нет фотографий; для них показана нейтральная заглушка. Наличие и цены подтверждаются питомником. Не меняйте изображения на вымышленные фотографии конкретных сортов.
