# Новъ — НЭО Питомник

Многостраничный сайт питомника на основе [neo-pitomnik.ru](https://neo-pitomnik.ru/). На главной сохранены оригинальная панорама, консультация агронома и три выгодных предложения. В каталоге 188 позиций и 159 вариантов. Порядок карточек и 16 страниц каталога соответствуют исходному магазину.

Две версии используют один каталог и дизайн. Каждая зона панорамы ведёт в свой раздел. Подписи видны на телефоне и при работе с клавиатуры. Источники кадров и фотографий услуг указаны в `public/assets/garden-map/sources.json` и `public/assets/original-services/sources.json`. Основное меню, тексты разделов и параметры фильтров сохранены в `app/data/original.json`.

- [Основная версия](https://yasinsckijtema1907-eng.github.io/neo-pitomnik/) включает исходные разделы, пять товаров распродажи и фильтры по высоте, контейнеру и цене.
- [Расширенная версия](https://yasinsckijtema1907-eng.github.io/neo-pitomnik/plus/) добавляет подборки по задаче, быстрый просмотр, фильтр по конкретному размеру, инструкцию по заказу и скачиваемый прайс. [Разбор решений конкурентов](docs/competitive-notes.md).

3D-сцена находится на главной после «Выгодных предложений». Ссылка «Как растёт дерево» под панорамой ведёт к ней напрямую. Модели Poly Haven используют PBR-текстуры 4096×4096 и лицензию CC0. Дерево можно поворачивать перетаскиванием или кнопками. На телефоне сначала показаны кадры 2160×3840, отрендеренные из этой же геометрии. Интерактивная модель с картами 2048×2048 загружается по желанию посетителя. При недоступном WebGL сохраняется анимация кадров. Источники, авторы и контрольные суммы находятся в `public/assets/trees/MODEL-LICENSES.md` и соседних JSON-файлах.

В разделе «О питомнике» возвращены оригинальная общая фотография команды и все шесть портретов. Источники изображений перечислены в `public/assets/team/sources.json`; имена и индивидуальные должности не выдумывались.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

## Сборка для GitHub Pages

```sh
npm run build:pages
npm start
```

Первая версия находится в `out/`, расширенная — в `out/plus/`. Все страницы генерируются отдельными HTML-файлами. Прайс создаётся из каталога при сборке второй версии. GitHub Actions автоматически собирает и публикует обе версии после изменения ветки `main`. Для локального просмотра откройте адрес из вывода `npm start`; для второй версии добавьте `plus/`.

## Заявки

Выбор растений хранится в браузере. Форма готовит письмо на `admin@neo-pitomnik.ru` с контактами и выбранными позициями. Посетитель открывает и отправляет письмо из своей почты; сайт не сообщает об автоматической отправке или сохранении заявки.

Оригинальный обработчик заявок для OpenAI Sites и Cloudflare D1 сохранён в `server/sites-inquiry-route.ts`, схема — в `db/` и `drizzle/`. Этот обработчик не запускается на GitHub Pages. Для автоматического приёма заявок понадобится отдельный сервер.

## Где редактировать

- `app/garden.tsx` — каталог, выбор растений, заявки и управление анимацией дерева;
- `app/premium-experience.tsx` — главная страница, навигация, футер и оформление описаний;
- `app/nov-editorial.tsx` и `app/nov-editions.css` — панорама, питомник и журнал;
- `app/nov-commerce.tsx` и `app/nov-shop-tools.ts` — подборки, фильтры, быстрый просмотр и страница покупателя;
- `scripts/build-editions.mjs` — сборка двух версий и прайса;
- `app/page-content.tsx` — содержание основных разделов;
- `app/about-team.tsx` — общая фотография и галерея команды;
- `app/growth-experience.tsx` и `app/tree-scene.tsx` — история роста и интерактивная 3D-сцена;
- `app/premium.css` — действующая система стилей для всех страниц;
- `app/refined.css` — оформление крупной сцены и блока команды;
- `public/catalog.json` — исходный ассортимент и цены;
- `public/blog.json` — статья исходного блога;
- `public/assets/` — фотографии, шрифты и кадры анимации.

У части товаров на исходном сайте нет фотографий; для них показана нейтральная заглушка. Наличие и цены подтверждаются питомником. Не меняйте изображения на вымышленные фотографии конкретных сортов.
